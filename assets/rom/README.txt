Bit-Rate-Rush / 8MB 単体ROM / 256x144

brr-trailer-8mb.sfc をSnes9xで開いてください。
MSU-1の.msu・.pcmファイルは不要です。この.sfcだけで映像と音声を再生します。

仕様:
  ROM: 8,388,608バイト（8MiB / 64Mbit）/ ExHiROM
  画像: 256x144 / カットごと64色以内 / SNESの15bit色
  映像: 約3.33fps（NTSCの画面更新18回ごとに1フレーム）/ 全531フレーム
  音声: 16kHz・モノラル・BRR / SNES標準DSPで再生
  長さ: 約2分39秒。再生終了後は最終画像で停止します。

容量内訳（10進数）:
  圧縮映像・パレット: 6,490,729バイト（約6.49MB）
  BRR音声:           1,434,042バイト（約1.43MB）
  上記合計:          7,924,771バイト
  残り:                463,837バイト（プログラム、表、配置余白など）

MSU-1版との違い:
  解像度、採用フレームのピクセル、桃色の本の専用パレットは維持しています。
  容量と展開処理のため映像を約3.33fpsへ減らしています。
  ズーム・パンは10fps/30fps版よりもコマ送り感が増えます。
  音声は44.1kHzステレオPCMから16kHzモノラルBRRへ変更しています。
  エミュレーターのFPS表示が約60でも、動画の更新頻度は約3.33fpsです。

検証:
  MacのSnes9x 1.63コアで全編を実行。
  531フレームすべてのVRAM画像が、採用した元の減色済みフレームと一致。
  64色制約、18更新ごとの表示間隔、展開遅れゼロを確認。
  元音声が鳴っている全編の区間で、コア出力音声が継続していることを検査。
  RetroArch + Snes9x / OpenGLで起動・再生を確認。
